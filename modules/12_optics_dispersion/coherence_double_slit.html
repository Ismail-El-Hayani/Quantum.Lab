Partial Coherence — Double-Slit Interference

A finite wave pulse hits a wall with two slits. Temporal partial coherence (spectral width Δλ) washes out high-order fringes. Visibility decays when path difference exceeds coherence length.

2-D Interference Pattern — Intensity stripes on screen

Heatmap of light intensity on the screen. Horizontal = screen position y (mm). Vertical repeats the profile to show vertical fringe stripes. Bright magenta = constructive (maxima), dark = destructive (minima). When Δλ > 0, high-order fringes fade because different wavelengths have different spacings.

Fraunhofer Double-Slit Intensity
I(y) = I₀ · sinc²(π a y / λ L) · cos²(π d y / λ L)
a = slit width  |  d = slit separation  |  λ = wavelength  |  L = screen distance

Path Difference & Visibility — Δr(y) and V(y) vs screen position

Cyan = geometric path difference Δr(y) = d·|y|/L. Magenta = visibility V(y) = (I_max − I_min)/(I_max + I_min). V starts at 1 and decays once Δr exceeds Lc. Green dashed = Lc = λ²/Δλ — fringes wash out beyond this.

Visibility for Rectangular Spectrum
V(Δr) = | sin(π · Δr · Δλ / λ²) / (π · Δr · Δλ / λ²) |
Δr = d·|y|/L  |  Δλ = spectral width  |  λ = central wavelength  |  Lc = λ²/Δλ

Screen Intensity Profile — I(y) vs position on screen

Classic double-slit Fraunhofer pattern. Cyan = fully coherent (Δλ = 0). Magenta = partially coherent — high orders blur. Red dashed = single-slit envelope sinc²(β). Orange / Green dotted = Slit 1 / Slit 2 alone.

Double-Slit Fraunhofer (Far-Field)
I(y) = I₀ · sinc²(π a y / λ L) · cos²(π d y / λ L)
β = π a y / λ L  |  δ = π d y / λ L  |  Δy = λ L / d = fringe spacing

Photon-Photon Correlation — Joint detection vs photon separation

Second-order correlation g⁽²⁾(Δx) — Hanbury Brown–Twiss effect. Photons from a chaotic source tend to bunch (arrive together).

  • Red solid = 0.5 + 0.5·|γ|²·I(Δx). Peak at Δx=0 → g⁽²⁾(0)=2. Decays to 0.5 over Lc.
  • Green dotted = interference structure = 0.5 + 0.5·I(Δx). Side peaks at Δy = λL/d.
  • Blue solid = uncorrelated baseline 0.5 (g⁽²⁾ = 1).
  • Cyan arrow = ±Lc span — distance where bunching survives.

Second-Order Coherence (HBT)
g⁽²⁾(Δx) = 1 + |γ(Δx)|²   where   |γ(Δx)| = |sinc(π · Δx / Lc)|
Δx = photon separation  |  γ = complex degree of coherence  |  Lc = λ²/Δλ = coherence length

Wave propagation: A finite wave packet (3–5 crests) travels toward a wall with two slits. Each slit emits circular Huygens wavelets. The overlap region shows interference fringes. One-shot pulse — not continuous.

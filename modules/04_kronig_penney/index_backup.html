From Atoms to Bands

A single atom has discrete energy levels. Bring 10²³ atoms together, and those levels blur into bands. The Kronig-Penney model is the simplest quantum system that shows exactly how this happens.

B. Theory — Why do gaps open at the Brillouin zone boundary?

In free space, an electron has energy E(k) = ħ²k²/2m — a single parabola with no gaps. When we introduce a periodic potential V(x+a) = V(x), the Schrödinger equation admits solutions of the Bloch form ψ(x) = u(x)e^{ikx} where u(x) shares the lattice periodicity.

Exact Kronig-Penney dispersion (square well barrier):

$$\cos(ka) = \cos(\alpha w)\cosh(\beta b) + \frac{\beta^2 - \alpha^2}{2\alpha\beta}\sin(\alpha w)\sinh(\beta b)$$

with \(\alpha = \sqrt{2mE}/\hbar\), \(\beta = \sqrt{2m(V_0-E)}/\hbar\), well width \(w = a-b\). For \(E > V_0\), \(\beta \to i\beta'\) and cosh/sinh become cos/sin.

The right-hand side can exceed 1 in magnitude. When that happens, there is no real k that satisfies the equation. Those energies are forbidden — they form the band gaps.

Key Insight: Bragg Reflection
The gaps open at k = ±π/a, ±2π/a, ... — exactly where electron waves satisfy the Bragg condition and get reflected. At these k values, forward and backward traveling waves interfere to create standing waves. The gap energy is the difference between the two standing wave charge distributions (one peaked at barriers, one peaked at wells).

Tight-binding limit (large V₀, narrow b): The bands are narrow and well-separated — each band comes from one atomic level. Nearly-free limit (small V₀, wide b): The bands are wide and the gaps are small — the electron behaves almost freely. Your course covers both extremes with the same unifying framework.

Semiconductor Bandgap vs Temperature — Varshni Equation

The bandgap shrinks with temperature because lattice vibrations screen the Coulomb potential. Si at 300K: E_g = 1.12 eV. At 600K it drops to ~1.0 eV — critical for high-temperature device operation.

Temperature300K
Varshni: E_g(T) = E_g(0) − αT²/(T+β)

Superlattice — N Quantum Wells → N Minibands

Coupling N quantum wells creates N minibands. Each well contributes one state, and tunneling splits them — a direct consequence of the Kronig-Penney model with finite barriers.

Bloch Oscillations — Electron in E-field + Lattice

An electron in a periodic potential under constant electric field undergoes periodic motion. In solids, scattering destroys oscillations (τ ≪ T_B). Observed in ultracold atoms and semiconductor superlattices.

🔲

Quantum Tunneling — WKB Transmission Probability

Classically, a particle with E < V₀ cannot cross a barrier. Quantum mechanically, it tunnels with probability T ≈ exp(−2κb). STM, flash memory, alpha decay, and RTDs all rely on this effect.

📈

Resonant Tunneling Diode — Negative Differential Resistance

An RTD sandwiches a quantum well between two thin barriers. At resonance, electrons tunnel through both barriers coherently. Off-resonance, current drops — NDR enables oscillators and ultra-fast switches.

D. Under the Hood — Numerical solver in pure JavaScript

This module solves the exact Kronig-Penney transcendental equation at each k-point using bisection. No approximations — you are seeing the exact quantum mechanical band structure for a square-well periodic potential.

function solveKP(V0, b, a, k) { const w = a - b; const cos_ka = Math.cos(k * a); // Find roots of f(E) = rhs(E) - cos(ka) = 0 // where rhs(E) is the Kronig-Penney right-hand side // We scan E ∈ [0, V0+5] for sign changes, then bisect const rhs = (E) => { if (E < 0) return Infinity; const alpha = Math.sqrt(2*E); // m = hbar = 1 if (E < V0) { const beta = Math.sqrt(2*(V0 - E)); return Math.cos(alpha*w)*Math.cosh(beta*b) + (beta*beta - alpha*alpha)/(2*alpha*beta) * Math.sin(alpha*w)*Math.sinh(beta*b); } else { const betaP = Math.sqrt(2*(E - V0)); return Math.cos(alpha*w)*Math.cos(betaP*b) - (betaP*betaP + alpha*alpha)/(2*alpha*betaP) * Math.sin(alpha*w)*Math.sin(betaP*b); } }; // Scan for sign changes of rhs(E) - cos(ka) // Each sign change corresponds to an allowed energy let roots = []; let E_prev = 0.01; let f_prev = rhs(E_prev) - cos_ka; for (let E = 0.02; E < V0 + 8; E += 0.01) { let f = rhs(E) - cos_ka; if (f_prev * f < 0) { roots.push(bisect(rhs, cos_ka, E_prev, E)); } E_prev = E; f_prev = f; } return roots; }

     Global “Playground” remediation checklist (apply once per module)

     1. Deferred init – Wrap all canvas‑creation and Plotly‑newPlot calls in a function that runs only after #section‑play becomes visible.
        js
        const playObs = new MutationObserver(muts => {
          for (const m of muts) {
            if (m.attributeName === 'style' && m.target.id === 'section-play' &&
                m.target.style.display !== 'none') {
              initPlayground();      // create canvas, Plotly, timers
            }
          }
        });
        playObs.observe(document.getElementById('section-play'),{attributes:true});

     2. Null‑ctx guards – Every draw routine starts with:
        js
        const ctx = canvas.getContext('2d');
        if (!ctx) return;

     3. Lazy‑plot dirty flag – Declare an object like:
        js
        const _plotDirty = {potential:false, tunneling:false, bands:false};
        function updateAll(){
            const mode = getActivePlayMode();
            plotmode;                     // rebuild only visible
            Object.keys(_plotDirty).forEach(k=>k!==mode && (_plotDirty[k]=true));
        }
        function setPlayMode(m){
            // … if dirty or not built, call plotm; else Plotly.Plots.resize(...)
        }

     4. Unique IDs – Prefix all module‑specific progress‑ring IDs (ring‑xx‑<mod>) and corresponding <span id="pct‑xx‑<mod>">. Use a simple search‑replace across the file (patch with
     old_string/new_string).
     5. Stat mirroring – After every XP/badge increment, push the new value to every sidebar variant:
        js
        const targets = ['stat-xp', 'stat-xp-story', 'stat-xp-theory'];
        targets.forEach(id => document.getElementById(id).textContent = newXP);

     6. Resize on tab switch – After setGameMode('play') or setPlayMode(...), call:
        js
        Plotly.Plots.resize(document.getElementById('plot-<id>'));

     7. Throttle heavy calculations – Wrap expensive solver calls in requestAnimationFrame or a debounce (setTimeout) to avoid flooding the UI on fast slider moves.
     Prioritisation (quick win → deep win)

     | Priority | Action                                                                                          |

     | 1        | Add the MutationObserver + null‑ctx guard to every module (≈ 30 min total).                     |

     Bottom line: The Playground sections work functionally but suffer from hidden‑init crashes, duplicate DOM IDs, and performance‑heavy eager re‑plots. Apply the above Socratiscode‑style fixes to make
     every Playground robust, responsive, and consistent across Story, Theory, and Playground tabs.
